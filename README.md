# IP 透镜 · VPS 网络信号检查

纯静态中文页面，可部署到 GitHub Pages。支持输入 IPv4 / IPv6，查看第三方数据库给出的粗略位置、国家/地区、ASN 与网络组织；不计算“纯净分”，也不自动显示 VPN、Proxy、Tor 或滥用威胁字段。

## 部署

本目录内容就是站点根目录。GitHub Pages 可从仓库的 `main` 分支根目录发布；页面资源采用相对路径，适用于项目站点子路径。没有后端构建步骤、密钥或额外依赖。

## IP 查询与隐私

- 每次查询都要求用户先主动勾选同意框；默认未勾选，查询开始后立即清除勾选状态。未同意或输入不是 IPv4/IPv6 时，不会向 IP 数据服务发送请求。
- 用户同意后，浏览器会直接向 `https://ipwho.is/{IP}` 发起 HTTPS 查询；查询的目标 IP 出现在请求路径中，服务也会看到发起连接的访客公网 IP。此页面不代理请求，不运行服务器端代码，也不保存查询历史。
- [IPWhois.io 隐私政策](https://ipwhois.io/privacy)说明使用数据可能记入日志，并可为所列处理目的保留，但未给出查询日志的具体删除期限。发布前核对时，该政策也没有承诺固定的短期留存窗口。
- [官方 API 文档](https://ipwhois.io/documentation)说明免费接口每日最多 1,000 次；通过 CORS 从网站请求时按来源域名计算，额度由该域名的访客共用。免费服务无 SLA，可能限流或不可用。
- 只向固定的 `ipwho.is` 主机发送 IP 查询；不接受域名、URL、端口或任意目标。不会查询 API 之外的威胁数据。

## VPS AI 连通性脚本

页面提供可下载的 `vps_ai_probe.py`。请在你自己的 VPS 上用 `python3 vps_ai_probe.py` 运行。脚本仅针对代码中列出的 6 个固定域名检查 DNS、TCP/443 和 TLS/SNI；不发起 API 请求，不需要账号或密钥，也不允许任意主机/端口。TLS 成功不代表地区支持、账户资格或 API 可用。
